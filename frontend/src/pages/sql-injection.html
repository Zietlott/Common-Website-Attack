SQL Injection

Tìm hiểu rủi ro khi dữ liệu đầu vào được kết hợp trực tiếp vào câu truy vấn SQL và cách xây dựng truy vấn an toàn.

SQL Injection là gì?

SQL Injection là lỗ hổng xảy ra khi dữ liệu đầu vào có thể làm thay đổi cấu trúc câu truy vấn cơ sở dữ liệu ngoài dự kiến. Hậu quả phụ thuộc vào quyền của tài khoản cơ sở dữ liệu và cách ứng dụng xử lý truy vấn.

Điểm cần nhớ: dữ liệu người dùng không nên được xem như một phần của cấu trúc câu lệnh SQL.

Hai cách xử lý cùng một yêu cầu đăng nhập

Cả hai ví dụ đều tìm tài khoản theo username. Khác biệt là dữ liệu đầu vào có bị ghép vào câu SQL hay được truyền thành tham số riêng.

Vulnerable · demo local

Ghép dữ liệu vào câu SQL

Username và password được ghép vào câu truy vấn. Nội dung nhập vào có thể làm thay đổi cách cơ sở dữ liệu diễn giải câu lệnh. 

const sql =
  "SELECT id, username FROM users " +
  "WHERE username = '" + username + "' " +
  "AND bcrypt_compare('" + password + "', password) = 1";

db.prepare(sql).get();
Secure · tham số hóa

Tách dữ liệu khỏi cấu trúc SQL

Tìm tài khoản bằng tham số riêng, sau đó kiểm tra password bằng hàm xác thực. Giá trị đầu vào không trở thành cú pháp SQL. 

const user = db
  .prepare("SELECT id, username, password FROM users WHERE username = ?")
  .get(username);

Mô phỏng đăng nhập

Nhập cùng một tài khoản thử nghiệm rồi chạy lần lượt cả hai chế độ để so sánh kết quả. Chỉ dùng dữ liệu giả trên backend local; không nhập mật khẩu thật.

Phạm vi an toàn: chế độ vulnerable chỉ được cung cấp cho bài lab local trong môi trường development. Không dùng thông tin cá nhân hoặc tài khoản đang sử dụng.

1. Thử cách vulnerable

Chạy mô phỏng ghép chuỗi SQL. Chỉ thử với dữ liệu mẫu trong môi trường local.

2. So sánh cách secure

Gửi cùng thông tin bằng truy vấn tham số hóa và kiểm tra password riêng.

Biện pháp phòng chống

  • Ưu tiên prepared statements và truy vấn tham số hóa.
  • Kiểm tra dữ liệu đầu vào theo định dạng mong đợi.
  • Áp dụng nguyên tắc đặc quyền tối thiểu cho tài khoản cơ sở dữ liệu.
  • Không để lộ thông tin lỗi nhạy cảm cho người dùng cuối.
